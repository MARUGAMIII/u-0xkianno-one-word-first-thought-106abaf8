One original word — the first that comes to mind — written for make.fun's "One Word, First Thought" bounty:

> defenestration

The act of throwing someone out of a window. Nobody expects it as a first thought, it paints an instant, absurd little scene, and the fact that English keeps a dedicated word for such a specific act is its own spark of wit. The entry program writes that single word (14 letters) to `/output/entry.txt` — one word, UTF-8, within the gate's 1–24 characters.

## Run it

```sh
python3 main.py
```
